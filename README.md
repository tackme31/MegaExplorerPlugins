# MEGA Explorer plugins

Plugins for [MEGA Explorer](https://github.com/tackme31/MegaExplorer), one folder each. See each
plugin's README for usage and installation.

| Plugin | What it does |
| --- | --- |
| [MegaDirStat](dirstat_plugin/README.md) | Shows what takes up the space in a folder, as a tree and a treemap. |
| [WD Tagger](wdtagger_plugin/README.md) | Tags images and videos with what is in them, using a WD14 model on the GPU. |
| [WD Tag Search](wdtagsearch_plugin/README.md) | Builds a search query over WD Tagger's tags, with suggestions and a match count. |
| [Duplicate Finder](dupfinder_plugin/README.md) | Finds the files with the same content under a folder. |
| [ZIP Search](zip_search/README.md) | Lists the files inside the ZIPs under a folder and saves one without downloading the archive. |
| [Slideshow](slideshow_plugin/README.md) | Plays the images in a folder as a slideshow. |
